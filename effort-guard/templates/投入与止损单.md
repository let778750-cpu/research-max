# 投入与止损单（空白模板）

按需填写，不逐次工具调用填表；轻任务不填本表，口述一句停止条件即可。未知项写"未知"，不填 0，不填示意数字。

## 1. 任务与判档

| 项 | 内容 |
|---|---|
| 任务 | 待填写 |
| 档位 | 待填写：轻／中／重／探索 |
| 判档依据 | 待填写 |
| 用户当轮目标与授权 | 待填写 |

## 2. 三格

**探索档填这一组：**

| 项 | 内容 |
|---|---|
| 问题（本轮想弄清什么） | 待填写 |
| 判别式停止条件 | 待填写：什么情况下算"再查也不改变问题图" |
| 每轮产出 | 待填写 |
| 探索额度（轮数／比例／时长） | 待填写 |

**中、重档填这一组：**

| 项 | 内容 |
|---|---|
| 成功判据 | 待填写：什么东西出现就算完 |
| 预算：时长 | 待填写：区间，未知写未知 |
| 预算：调用或算力 | 待填写：区间，未知写未知 |
| 预算：人工复核 | 待填写 |
| 停止条件 | 待填写：判据满足／预算到点／同一根因两次未修复 |
