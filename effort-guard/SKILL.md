# 投入与止损技能

自包含技能，随 research-max 技能集分发。本技能管"要不要做、做多大、什么时候停"，不管"怎么做才对"——研究设计与统计见 research-execution 技能，选题与调研见 research-topic 技能，写作见 paper-writing 技能，汇报措辞见 turn-report 技能。

核心判断：模型优化的是"当前证据下的完成概率"，研究者优化的是"总成本，含未来维护"。两者不一致时，模型会合理地多做、多写、多加兜底；它对自己"还要花多少"的估计也不可靠，不能拿来自我刹车。所以不靠提醒模型"注意成本"，靠外置判据、可核对的账和便宜的止损点。

## E1—E9 速览

以下为速览，执行时读 references/ 原文；阈值由任务卡或项目约定给出，技能只给判据。

| 编号 | 规则 | 一句话判据 |
|---|---|---|
| E1 | 先算账，分两种账 | 收敛型任务写成本三格（成功判据、预算区间、停止条件）；探索型任务写探索三格（问题、判别式停止、每轮产出）；轻任务免填 |
| E2 | 先摆路线再收敛 | 重任务动手前给 2—3 条可比较路线，各写一句判据与代价，选一条执行 |
| E3 | 最小起点 | 第一版只做能回答当前问题的最小实现；探索性原型允许一次性、可丢弃 |
| E4 | 一次一处已定位原因 | 改前写"根因是 X，改这里应当改变观测 Y"；顺手改动另列 |
| E5 | 同一失败两次停手 | 同一根因连续两次修复仍复现就停，给已排除项、候选根因、一项区分检查；只管修复循环 |
| E6 | 三道闸，信息闸优先 | 先问"再来一轮能否改变判断"，再问成本与维护；维护闸不否决未试过的探索 |
| E7 | 采样要有选择器 | 多候选只在有验证器或明确判据时采样；没有就把预算转向造判据 |
| E8 | 重写先计价 | 列旧方案失败证据、省掉的迭代、迁移与重学成本；缺一不做 |
| E9 | 汇报带成本账 | 实际耗时与调用、费用（未知标未知）、重试与返工、探索轮次与命中 |

## 场景流程

| 场景 | 做法 |
|---|---|
| 开始一件多步任务 | 先判档：轻／中／重／探索；按档填三格。重任务先摆 2—3 条路线 |
| 做到一半卡住 | 先分"没定位"还是"定位了修不动"：没定位回去诊断，不靠加大测试量提概率 |
| 同一失败第二次修复后又复现 | 触发 E5：停止继续打补丁，交出已排除项、剩余候选根因与一项能区分它们的检查 |
| 想重构、换框架或重写 | 走 E8 三问；探索期的一次性原型不计，但记放弃理由 |
| 探索性工作：选题、调研、方法发散 | 用探索三格；停止看"补查是否还改变问题图"，不看已花多少 |
| 想并行多方案或多采样 | 先过 E7：有没有验证器或判据；没有就先造判据，不先加样本 |
| 交付 | 按 E9 给成本账；重试与返工照实写，不隐藏 |

## 贯穿红线

- **成本是判据，不是禁令。** 探索期的停止条件是信息增益，收敛期才是成本；用成本否决一个还没试过的方向属于误用。
- **停机不等于偷工。** 正确性证据、失败与负结果、边界交代、统计功效所需的重复，不能因省成本删掉。
- **自估不可靠。** 模型对自己还要花多少的估计覆盖率很低，预算与停顿点要写在任务卡或当轮回复里，不靠心里"我觉得够了"。
- **不双记账。** 费用、token 与重复次数沿用项目既有记录（任务卡、实验协议、接续交代），本技能不新建第二本台账。
- **冲突顺序：** 用户当轮目标 > 项目 AGENTS 的项目事实 > 本技能判据；技能或模板的建议不自动升级为审批门槛。

## 交付闸门

1. **轻任务**：无强制表格，口述一句停止条件即可。
2. **中／重／探索任务**：三格齐全；重任务另有路线与回滚点；探索任务有每轮产出与判别式停止。
3. **汇报**：含成本账与返工次数；实际值不可得标未知，不换算、不宣称节省百分比。
4. **机械检查**：本技能刻意不配脚本。成本判据依赖任务上下文，机械检查只能查字段是否为空，最容易被形式化绕过；填表本身也花钱，与本技能用意相反。判断质量由复盘的三个问题核对。

## 边界

- 适用于计算、仿真、实验、文献调研、工程实现与写作迭代的过程决策；实验设计、统计推断、论文格式与投稿操作不在本范围，按名使用对应技能。
- 本技能不判断研究价值，也不替研究者决定要不要做某个方向；它只让"做多大、做多久、什么时候停"变得可核对。
- 默认阈值（如同类修复两次）是可覆盖的起点，不是科学阈值；改动要写在任务卡，不静默放宽。
- 规则在本目录单一维护，模板只保留待填内容；不复制其他技能的判据，其他技能按名提及本技能。
