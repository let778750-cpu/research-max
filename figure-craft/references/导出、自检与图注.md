# 导出、自检与图注

本文件维护 FIG10—FIG11。来源：原 paper-writing 技能 F13、F14（2026-11-12 据 nature-figure 的导出与渲染后检查项摘编），2026-11-21 迁入本技能，并补机械检查边界与图注最小项。

## FIG10　导出与可编辑性

| 图的内容 | 首选格式 | 说明 |
|---|---|---|
| 折线、散点、柱、箱线等数据图 | PDF、SVG、EPS | 矢量，文字保持可编辑 |
| 图像与数据混排 | PDF 或 EPS 内嵌位图 | 位图部分按下方分辨率要求 |
| 照片、显微、遥感影像 | TIFF 或 PNG | 最终尺寸下 300—600 dpi |
| 线稿 | 不用 JPEG | JPEG 压缩在细线边缘产生伪影 |

- **文字不转曲、不栅格化**：SVG 设 `svg.fonttype='none'`；PDF 嵌入字体而不转曲（matplotlib 常用 `pdf.fonttype=42`）；EPS 确认字体已嵌入。转曲后的图无法再改字，投稿返修时只能重画。
- **最终尺寸直接出图**：`figsize` 按目标毫米换算；不要导出大图再缩，缩图会改变实际字号与线宽。`bbox_inches='tight'` 会改变实际画布尺寸，若使用需记录最终尺寸并按它核对分辨率。
- **有效分辨率**按"像素宽 ÷（刊印宽度毫米 ÷ 25.4）"计算；修改 dpi 元数据或上采样不产生原始细节。
- **颜色空间**：按目标刊要求提供 RGB 或 CMYK；转换后要重新检查灰度与色觉可分。
- **不伪装矢量**：位图嵌入 SVG 不叫已矢量化；格式变化不自动改变图源与可编辑性。
- **命名与归档**：图号、版本、日期、目标刊；绘图脚本、源数据版本、样式文件、导出参数与自检记录同版本归档，便于复跑与返修。

## FIG11　出图自检与图注统计最小项

自检分三层，逐层记录，不用一层替代另一层：

**第一层 程序检查**（`scripts/figure_lint.py`，只查确定性项）：

| 检查 | 失败或警告条件 |
|---|---|
| 最小字号 | 文本实际字号低于设定下限（默认 5 pt）→ 失败 |
| 文字可编辑 | SVG 无文本节点、PDF 无可用字体 → 失败（已转曲） |
| 有效分辨率 | 位图在目标宽度下低于设定下限（默认 300 dpi）→ 警告 |
| 画布尺寸 | 实际宽度与目标宽度偏差超过 2 mm → 警告 |
| 矢量纯度 | PDF/SVG 内含位图 → 警告 |

用法与退出码：`python scripts/figure_lint.py <导出件> --width-mm <目标宽度>`；0 通过、1 警告、2 失败。依赖 Pillow 与 PyMuPDF，缺失时报错退出 2。**通过只代表机械项通过，不替代视觉与统计核对。**

**第二层 视觉审读**（导出 PNG 预览后逐项看）：文本是否被裁切或遮挡；图例是否压住数据；面板标号位置是否一致；可比面板是否对齐、等宽；灰度下各类是否仍可分；刻度标签是否重叠；阅读顺序是否清楚。

**第三层 人工核对**（内容层）：误差条与区间定义是否与统计协议一致；n 与独立单位是否正确；显著性标注的检验与校正是否写明；图注与正文数字、单位、方法名是否一致；示意内容是否已声明为示意。

**图注统计最小项**：

| 项 | 写什么 |
|---|---|
| 样本量 | n 与独立单位定义（个体、批次、场景、随机种子） |
| 中心量与散布 | 均值／中位数；SD／SEM／IQR／95% CI，写明哪一种 |
| 区间来源 | 解析式、bootstrap 次数、模型预测区间 |
| 检验 | 检验名称、是否配对、是否多重比较校正 |
| 数据来源 | 数据文件名与版本，或本图文件名对应的结果表 |
| 软件与版本 | 可选，但用非常规绘图库时建议写 |
| 机器学习项 | 数据划分、随机种子或折数、指标与基线定义（按需） |
| 示意声明 | 非实测内容必须标"示意" |

图注组织与正文前后解读按 paper-writing 的 F5 执行；图注最小项与 research-execution 统计报告清单同源不同粒度，缺项要么补齐，要么写明不适用。
