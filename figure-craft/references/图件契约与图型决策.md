# 图件契约与图型决策

本文件维护 FIG1—FIG3。来源：原 paper-writing 技能 F8、F9（2026-11-12 据 nature-skills 的 nature-figure 摘编），2026-11-21 迁入本技能，并补数据剖面与图型决策表。

## FIG1　图件契约先于代码

写绘图代码前先落契约，六项缺一不开工：

| 要素 | 写什么 | 不合格的样子 |
|---|---|---|
| 结论句 | 一句话、带动词，能被这张图支持 | "结果展示""性能对比" |
| 结果级问题 | 这张图回答哪一个可判定的问题 | 一图同时回答三个问题 |
| 面板地图 | 每面板的唯一问题、证据层级、输入数据 | 先画再补面板说明 |
| 证据层级 | 主证据、验证、对照，各自占多少视觉重量 | 对照与主证据同样醒目 |
| 统计项 | n、独立单位、中心量、区间、检验 | 图注事后补 |
| 数据版本与出口 | 输入文件与版本、目标刊印尺寸、格式 | 从最新目录随手取数 |

契约的用处是让"删面板"有依据：与结论句无关的面板，即使好看也删。多张输入表可同属一条证据链，一张表也可支撑多个面板，判断依据是结论句而不是文件数。

契约落在[图件契约卡](../templates/图件契约卡.md)；数据确定性按 paper-writing 技能 F2 执行，本技能不重复。

## FIG2　数据剖面先于选图

选图前先看数据，不看图库。逐项过一遍：

| 项目 | 看什么 | 影响的选择 |
|---|---|---|
| 变量类型 | 连续、离散、分类、时间、计数 | 坐标类型与图型 |
| 单位与量级 | 数量级、是否跨零、是否长尾 | 对数轴、是否必须从零起 |
| 每组样本量 | 每组 n 与独立单位定义 | 是否显示个体点 |
| 分布形状 | 偏态、双峰、离群点 | 箱线、提琴、ECDF 或点图 |
| 缺失与排除 | 比例与机制 | 分母、图注与是否分面 |
| 配对与重复 | 同一单元是否被多次测量 | 配对图而非独立柱 |
| 分组平衡 | 各组条件、批次、环境是否可比 | 分面而非合并 |
| 数据版本 | 是否冻结或独立核验 | 能否作为主证据入图 |

剖面结论只改画法，不改研究结论。剖面发现每组 n=3、缺失 40% 或量级差三个数量级时，先回到数据与统计处理，不靠图形修饰掩盖。

## FIG3　图型决策

按"论证目标 × 数据形态"查表。默认首选只是起点，换成别的图型要写清理由。

| 论证目标 | 数据形态 | 首选 | 避免 |
|---|---|---|---|
| 组间比较 | 各组独立样本，n<10 | 点图或箱线叠加全部个体点 | 仅均值加误差条 |
| 组间比较 | 各组独立样本，n≥10 | 箱线加抖动散点；必要时提琴图 | 三维柱、双 Y 轴 |
| 配对比较 | 同一单元前后或同体两法 | 配对哑铃图或斜率图 | 两组独立柱并排 |
| 分布比较 | 偏态、双峰或需看分位 | ECDF、分位数箱线、雨云图 | 只报均值±SEM |
| 关系 | 两个连续变量 | 散点加拟合与区间带 | 只给相关系数、只画回归线 |
| 响应 | 随时间、参数或剂量变化 | 折线加区间带或分位数带，必要时分面 | 用平滑线掩盖逐点不确定性 |
| 排序或排名 | 多对象单指标 | 点图或棒棒糖图 | 排序后连线、环形图 |
| 相关或矩阵 | 多变量、混淆矩阵、相关性 | 热图，感知均匀色图，标数值或图例 | 彩虹色、遮蔽对角却不说明 |
| 残差诊断 | 模型拟合后的残差 | 残差-拟合、QQ、尺度-位置、残差-顺序 | 只看 R² |
| 分类性能与敏感性 | ROC、PR、参数扫描 | ROC/PR 标基线，混淆矩阵标数值，tornado 或热图 | 单指标柱状图代替整条曲线 |

选择判据：

- **能显示个体与不确定性的图型优先。** 一个图型如果只能显示均值，先问为什么不能显示个体。
- **图型跟着论证走，不跟着美观走。** 同一问题换图型必须同时换论证，不能只为好看。
- **维度过多先拆。** 一张图超过约十二个可见系列时，拆分面或拆图，不靠缩小图例硬塞。
- **视觉差异不等于统计差异。** 图型不能替代检验；需要检验时在图上标注检验与校正，或放补充材料。
- **禁用项默认否决。** 双 Y 轴、三维装饰、饼图、截断纵轴、彩虹色图，出现即为[反模式](反模式清单.md)，除非有书面理由与图注说明。

## 反例

- 先跑通默认 `plt.bar(mean)`，再补一句"误差条为标准差"，而不是先问 n 与分布。
- 用同一张图回答"方法更好"与"误差更小"两个问题，面板分工不明。
- 为了图面整齐，把不同场景的指标画进同一纵轴。
- 相关性热图用彩虹色并把不显著格子留白，却不说明留白含义。
