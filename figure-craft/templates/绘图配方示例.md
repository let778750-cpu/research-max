# 绘图配方示例

示例代码，不构成规则。每条只演示一个科学区分，数据为随机生成（固定种子），不得当作结果。正式图按[图件契约卡](图件契约卡.md)替换数据、统计与样式，并按 [FIG11](../references/导出、自检与图注.md) 自检。示例按后端无关规则写成 matplotlib，其他后端按同构实现。

## 1　组间比较：箱线加个体点（FIG5）

适用：各组独立样本、n 较小。保留全部个体点，箱线只作汇总。

```python
import matplotlib.pyplot as plt
import numpy as np

rng = np.random.default_rng(0)  # 示例数据
groups = {"基线": rng.normal(0.0, 1.0, 8), "本方法": rng.normal(0.6, 1.1, 8)}

fig, ax = plt.subplots(figsize=(3.5, 2.6))
ax.boxplot(list(groups.values()), widths=0.5, showfliers=False)
for index, values in enumerate(groups.values(), start=1):
    jitter = rng.uniform(-0.08, 0.08, values.size)
    ax.scatter(np.full(values.size, index) + jitter, values, s=14, zorder=3)

ax.set_xticks(range(1, len(groups) + 1), list(groups))
ax.set_ylabel("指标（单位）")
fig.savefig("group_comparison.svg")
```

## 2　配对比较：哑铃图（FIG5）

适用：同一单元的前后测量或两种方法同体测量。连线表达配对，不画成两组独立柱。

```python
import matplotlib.pyplot as plt
import numpy as np

rng = np.random.default_rng(1)  # 示例数据
before = rng.normal(0.0, 1.0, 10)
after = before + rng.normal(0.5, 0.3, 10)

fig, ax = plt.subplots(figsize=(3.0, 2.6))
for low, high in zip(before, after):
    ax.plot([0, 1], [low, high], color="0.6", linewidth=0.8, zorder=1)
ax.scatter(np.zeros_like(before), before, s=18, zorder=2, label="处理前")
ax.scatter(np.ones_like(after), after, s=18, zorder=2, label="处理后")

ax.set_xticks([0, 1], ["处理前", "处理后"])
ax.set_ylabel("指标（单位）")
ax.legend(frameon=False)
fig.savefig("paired_dumbbell.svg")
```

## 3　响应曲线：折线加区间带（FIG6）

适用：随参数、时间或剂量变化。区间来源与 n 必须写进图注；示例中的区间仅作画法演示。

```python
import matplotlib.pyplot as plt
import numpy as np

rng = np.random.default_rng(2)  # 示例数据
x = np.linspace(0, 10, 21)
center = 10.0 - 0.6 * x
half_width = 0.4 + 0.05 * x  # 示例：由重复运行的标准误换算，正式图写明区间类型
observed = center + rng.normal(0.0, 0.2, x.size)

fig, ax = plt.subplots(figsize=(3.5, 2.6))
ax.fill_between(x, center - 1.96 * half_width, center + 1.96 * half_width,
                color="0.85", linewidth=0)
ax.plot(x, observed, marker="o", markersize=3)
ax.set_xlabel("参数（单位）")
ax.set_ylabel("响应（单位）")
fig.savefig("response_band.svg")
```

## 4　残差诊断四联（FIG6）

适用：回归或拟合后的模型检查。四张图缺一不可；只看 R² 不构成诊断。

```python
import matplotlib.pyplot as plt
import numpy as np

rng = np.random.default_rng(3)  # 示例数据
fitted = rng.normal(5.0, 1.0, 200)
residual = rng.normal(0.0, 0.3 + 0.05 * np.abs(fitted - 5.0))
order = np.arange(residual.size)

fig, axes = plt.subplots(2, 2, figsize=(6.0, 4.6))
axes[0, 0].scatter(fitted, residual, s=8)
axes[0, 0].axhline(0.0, color="0.3", linewidth=0.8)
axes[0, 0].set_xlabel("拟合值")
axes[0, 0].set_ylabel("残差")

axes[0, 1].hist(residual, bins=20)
axes[0, 1].set_xlabel("残差")
axes[0, 1].set_ylabel("频数")

axes[1, 0].scatter(fitted, np.abs(residual), s=8)
axes[1, 0].set_xlabel("拟合值")
axes[1, 0].set_ylabel("绝对残差")

axes[1, 1].plot(order, residual, linewidth=0.8)
axes[1, 1].set_xlabel("观测顺序")
axes[1, 1].set_ylabel("残差")

fig.tight_layout()
fig.savefig("residuals.png", dpi=300)
```

## 5　多面板：统一标号与共享轴（FIG7）

适用：组图。标号位置统一放在近左上的 axes 坐标，可比面板共享纵轴。

```python
import matplotlib.pyplot as plt
import numpy as np

rng = np.random.default_rng(4)  # 示例数据
fig, axes = plt.subplots(1, 3, figsize=(7.0, 2.4), sharey=True)
for ax, shift in zip(axes, (0.0, 0.5, 1.0)):
    ax.scatter(rng.normal(shift, 1.0, 30), rng.normal(0.0, 1.0, 30), s=8)
    ax.set_xlabel("条件（单位）")

axes[0].set_ylabel("响应（单位）")
for ax, label in zip(axes, "abc"):
    ax.text(-0.18, 1.06, label, transform=ax.transAxes,
            fontsize=8, fontweight="bold", va="top")

fig.tight_layout()
fig.savefig("multi_panel.pdf")
```
