# 科研图件技能

自包含技能，随 research-max 技能集分发。本技能管"给定结果数据，怎样做成一张能发表、能被审读的图"；图的科学角色与论文中的位置、数据确定性与图源诚信、三线表与投稿版式仍归 paper-writing 技能 F1—F7，本技能不复制。两者联动：图件生产完成后固定回 paper-writing 的 F1—F7 与 F6 验收；数据只从冻结或独立核验的结果确定性绘制（F2）。

核心判断：**图型由论证目标与数据形态共同决定，不由模板或输入表决定。** 先写清这张图要让读者相信什么，再剖面数据；证据不足以支撑某个图型时，先补统计或改图型，不靠装饰、截轴或配色制造差异。

## 场景流程

| 场景 | 做法 |
|---|---|
| 只有一份数据，不知画什么 | 先剖面（FIG2）→按论证目标查决策表（FIG3）→填[图件契约卡](templates/图件契约卡.md) |
| 组间比较、要标显著性 | 先看每组 n 与分布（FIG5）；误差条写明类型与独立单位（FIG4） |
| 时间、参数或剂量响应曲线 | 响应曲线加区间带（FIG6）；写明区间来源、n 与是否逐点独立 |
| 模型或测量的误差分析 | 残差、QQ、校准图与一致性图（FIG6）；图注给检验方法 |
| 多面板组图 | 一图一主张；总览→偏离→关系（FIG7）；统一配色与标号 |
| 投稿前出图 | 最终尺寸（FIG9）→矢量导出（FIG10）→figure_lint→视觉审读（FIG11） |
| 审稿人质疑图 | 回 FIG4、FIG5 与[反模式清单](references/反模式清单.md)，先查误差定义与个体显示 |

## 贯穿红线

- 定量结果图从冻结或独立核验的结果确定性绘制（paper-writing F2）；没有数据时提供图形设计，不补随机数字当主结果。
- 从论证目标出发选最少面板，不从模板或输入表出发（FIG1）。
- 误差条、区间与显著性标注必须能回答"表示什么、n 多少、独立单位是什么"；答不上来就不画（FIG4）。
- 自动检查通过不等于视觉验收通过；字号、对齐与清晰度以导出件实测为准（FIG11）。
- 配色在灰度打印与色觉模拟下仍可辨，不靠颜色单一编码（FIG8）。
- 图中文字保持可编辑，不转曲、不栅格化线稿（FIG10）。

## 交付闸门

1. **契约与剖面**：图件契约卡填好，图型选择写明理由（FIG1—FIG3）。
2. **生产**：按 FIG3—FIG10 执行；图注按 FIG11 最小项。
3. **机械检查**：`python scripts/figure_lint.py <导出件> --width-mm <目标宽度>`，退出码 0 通过、1 警告、2 失败；依赖 Pillow 与 PyMuPDF，缺失时脚本报错退出，不联网安装。
4. **视觉审读**：缺字、裁剪、图例压数据、面板对齐、灰度可分、标号位置逐项看；记录后回改。
5. **回验收**：回 paper-writing 的 F1—F7 与 F6 逐项核对；契约卡、自检记录与导出件同版本归档。

## 边界

- 不做架构图、流程图、示意图、封面图与 AI 生图；其来源记录与诚信边界按 paper-writing 的 F1、F3 执行。
- 不承诺期刊模板合规；尺寸、字号与线宽的典型值只是起点，投稿前核对当期期刊指南与项目 `submission_profile.json`。
- 不规定绘图库，规则按后端无关写法；样式模板与配方示例只给 matplotlib 一份。
- 与 paper-writing 的 F1—F7 表述冲突时以 F1—F7 为准，并修订本技能对应条目。
- 规则在本目录单一维护；paper-writing、research-execution、report-writing 按名提及本技能，不复制副本。
