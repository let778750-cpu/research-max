# 选题与调研技能

自包含技能，随 research-max 技能集分发使用。解决两件事：随证据探索、调整并形成可研究的问题，以及把论文读到能核验、能讨论、能迁移。研究价值判断先于方法包装；阅读深度以能否回到原文证据衡量。

### 各规则一句话要求

以下为速览，执行时读 references/ 原文。

**四步法**：第一步讲清领域研究什么、能观测什么、哪些任务成熟哪些仍缺定义（研究活跃程度不按刊名或论文数量排序）；第二步逐场景回答"谁研究谁→能获得什么信息→判断什么→为何难→已有解法→还缺什么"，形成候选问题或待澄清的未知；第三步逐篇核清数据来源、处理与泄漏，数据/代码/权重/生成器分别登记公开状态；第四步重建方法全过程，分清作者声称的创新与实验支持的增量，资源分三类估算；最后给出有依据的探索行动或选题建议及判别条件。

**问题与创新论证**：从观察和困惑起步，按证据动态聚焦，区分研究方向、探索问题、下一项检查与论文主张；问题合同五问先于组件选择，正式主张按研究类型完成最近邻与证据论证；引用候选、知识库候选、学习范文分开管理；范文按适配性与科学质量选择，不以刊名、年份或下载数代替。

**P 论文精读**：P1先定阅读目的与深度（筛选/理解/引用/复现/综合，阅读范围、核验状态、执行状态是三个维度）；P2三遍阅读加回看复述；P3证据链可回到原件，缺口区分未找到/未报告/无法取得/证据冲突/不适用；P4机制讲到可跟做，贯穿实例S01加失败例；P5按论文类型选证据问题；P6开源材料先定位再按目标决定是否运行；P7有证据地批判、有条件地借鉴；P8 AI用于定位提取、核验判断保留为可审查动作；P9按本轮目标交付检查。

讨论与实验方案形成可独立使用；执行工具由用户针对具体任务选择。形成当前实验问题时，按[问题与创新论证](references/问题与创新论证.md#从讨论形成当前实验问题)交代判别问题、输入、方法与结果用途，交给 research-execution 消费，不自动启用跨 Harness 运行。

## 场景流程

| 场景 | 做法 |
|---|---|
| 宽泛方向细化、前沿调研或进展整理 | 按[四步法](references/研究调研与选题四步法.md)推进，落在[研究问题与文献卡](templates/研究问题与文献卡.md)；进展报告文体遵循 report-writing 技能，四步法不规定报告章节形状 |
| 从现象或困惑起步、多轮讨论或重新审视方向 | 按[问题与创新论证](references/问题与创新论证.md#按证据动态聚焦)判断展开与聚焦；具体检查与取舍更新按 research-execution 技能的探索短循环执行 |
| 定题与查新 | 问题合同五问＋最近邻与反证；退出条件见问题与创新论证末节 |
| 论文精读、代码拆解或讨论准备 | 按阅读目的选P1深度档，用[单篇论文精读模板](templates/单篇论文精读模板.md)记录；先解释再判断 |
| 链接打不开、声称开源但取不到 | 按四步法第三步公开状态六行表记录（"未找到公开说明"不能断言作者不公开；"链接不可访问"不改写为"不公开"），缺口用语按[P3](references/论文精读与证据核验规范.md#p3)区分（未找到／未报告／无法取得／证据冲突／不适用） |
| 学习范文与句式表达 | 范文选择标准见[问题与创新论证](references/问题与创新论证.md#选择表达学习范文)；拆解与句式训练方法见 paper-writing 技能 W9 |

## 贯穿红线

- 研究活跃程度与选题价值不按刊物声望、论文数量、名称新颖或下载数排序；候选数量不设门槛，不设"读够N篇才能提选题"的合格线。
- 下载数量不能代替阅读深度；关键文献必须标出实际阅读范围（摘要/章节/全文/代码检查/结果复算）。
- 论文公开不等于数据公开；能够下载不等于允许再分发；公开状态是核查时点的证据，不是永久属性。
- AI 给出的课题清单是候选，不能代替对问题价值和可行性的判断；多来源相互同意不构成独立验证。
- 阅读范围不足以支持"首次""领域空白"时，只写当前检索范围内的观察并给补查方向。
- 同一工作的多个版本不能当独立发现；文献篇数不等于独立证据数。
- 原图身份以核实为准，不能用生成图片补成"原图"；图文身份正确和预览可见是两个结论。

## 交付闸门

1. **调研交付**：读者能从当前问题或未知追到已有依据，分清已做与待做，知道下一项检查会怎样改变选择；早期不必产生论文题目（四步法末节完成标准）。
2. **精读交付**：按P9检查清单逐项核对——复述、重建、核验决定性一步、主张回到证据、开源与执行范围分别准确记录。
3. **图文核验**：嵌入原图时按[阅读笔记原图规则](references/论文精读与证据核验规范.md#reading-figures)两步核验（链接指向正确文件＋目标编辑器实际预览），不预填"已核验"。

## 边界

- 适用于实验、观察与理论研究的选题调研与论文精读；非论文报告的写作遵循 report-writing 技能，实验执行、数据准入、统计分析遵循 research-execution 技能，论文写作遵循 paper-writing 技能，各自按名使用不复制规则。
- 四步法是内容核查顺序，不要求报告照抄四个章节；精读深度按问题升级，不要求每篇完成十三节。
- 模板保持空白，未知项按P3缺口用语区分，不把通行做法补写成论文报告的内容。
- 规则在本目录单一维护；共享模板（探索记录、主张与证据表）随 research-execution 技能分发，本技能只按名提及。
