# research-topic：选题与调研技能

面向领域科研人员及其 AI 助手，覆盖从宽泛研究方向到可研究问题的全过程：领域调研四步法、问题合同与创新论证、论文精读与证据核验（P1—P9）。

## 适用范围

- 宽泛方向的调研与选题：前沿梳理、场景拆解、数据证据核验、方法重建、候选想法取舍
- 系统性文献检索与综述证据综合：检索式、来源分级、引用核验、矛盾裁决、综合矩阵（D1—D8）
- 论文精读与证据核验：按阅读目的分层阅读、开源材料定位、有证据的批判与借鉴
- 不适用：论文写作（paper-writing）、实验执行与数据分析（research-execution）、非论文报告（report-writing）

## 目录结构

│   ├── 深度调研与文献综合规范.md       # D1—D8：检索式、迭代与停止、去重、来源分级、引用核验、矛盾裁决、综合矩阵、失败路径

## 使用方式

**AI 助手**：从 `SKILL.md` 进入，按场景流程定位规则文件，按需加载。

**人工使用**：直接阅读 references/；调研落在 `templates/研究问题与文献卡.md`，精读用 `templates/单篇论文精读模板.md`。

## 核心立场

- 研究价值不按刊名声望、论文数量或下载数排序；阅读深度以能否回到原文证据衡量
- 探索可以从观察和困惑开始，但形成主张前必须补最近邻、竞争解释与可证伪论证
- 公开状态如实登记：论文公开≠数据公开，未找到公开说明≠作者不公开
- 规则在本目录单一维护；与其他技能的共享物只按名提及
