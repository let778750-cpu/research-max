# 研究问题与文献卡

宽泛方向的调研按[四步法](../references/研究调研与选题四步法.md)使用下列字段；已经明确的问题直接填写“问题合同”。详细文献与数据记录用链接引用，不重复抄写。

## 方向与场景比较

- 调研目的、范围与截止日期：
- 关键概念及容易混淆的任务边界：
- 综述、代表研究、成熟基线和反证入口；各自实际阅读范围：

| 具体场景与判断目标 | 可用信息与困难 | 必要领域知识及方法 | 数据、处理与标签证据 | 资源、竞争方法及研究缺口 |

|  |  |  |  |  |

- 数据、代码、模型权重、生成器各自的公开状态、许可与核查日期：
- 时间可用性、独立单位与训练测试隔离的核查位置：
- 未获得或未核验的关键材料：

## 问题合同

- 领域对象、任务及现实后果：
- 希望解释或改善的可观测量：
- 当前成熟做法及具体失效条件：
- 待检验假设；竞争解释：
- 关键证据从哪里获得；不能直接观测的量：
- 最小可行试验；能推翻假设的结果：
- 正结果与负结果分别允许提出什么结论：
- 人力、时间、数据权限与资源约束：

## 最近邻比较

| 文献及原文位置 | 研究对象与前提 | 已解决问题 | 本研究差异 | 最强对照与可能反证 |
|---|---|---|---|---|
| 待填写 | 待填写 | 待填写 | 待填写 | 待填写 |

“首次”“通用”“优于传统方法”必须给出检索范围及可验证依据；否则换成实际研究内容。复用成熟算法可以成立，贡献须来自有证据的新问题、新机制、新数据或新发现，而非把已有模块改名。

## 单篇阅读入口

统一使用[单篇论文精读模板](单篇论文精读模板.md)。筛选时只填其第1、2、13节；深读按适用主题展开。阅读深度与证据状态见[精读规范](../references/论文精读与证据核验规范.md)，本卡不再维护第二份单篇字段。

最近邻表引用单篇笔记及证据位置，按需要增加可比条件、共享数据/研究关系、分歧解释与补证行动；不重新抄写各篇完整内容。
