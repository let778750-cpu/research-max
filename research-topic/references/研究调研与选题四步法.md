# 研究调研与选题四步法

用于把宽泛研究方向拆成可研究的具体问题，以及向导师、合作者说明研究推进到了哪里。主线为：**领域前沿 → 具体场景 → 数据证据 → 方法与可行性**，最后对照自己的研究储备与候选想法作出选题判断。

这四步整理自用户提出的调研路径。此前另列的“解释共同讨论的候选想法”保留为收束部分，并未省略。它们是内容核查顺序，不要求报告照抄四个章节，也不要求每个场景使用相同段落长度。

已有明确问题的单篇精读、局部补证或文字修改，可直接进入相关步骤。单篇阅读深度遵循[精读规范](论文精读与证据核验规范.md)，新颖性判断遵循[问题与创新论证](问题与创新论证.md)。

## 第一步：把领域边界与研究前沿讲清楚

先回答这个方向究竟研究什么：对象是什么，能观测什么，要解释或判断什么，输出怎样用于实际决策。拆开容易混淆的概念，说明数据标签能支持哪一层结论。检测变化、识别行为、推断原因或目标，不能仅因名称相近就视为同一个任务。

用权威综述建立框架，再回到代表性研究论文、作者资料与公开基准核查。记录检索截止日期、渠道、主题词、纳入与排除理由；覆盖近期连续研究，也追溯必要的基础工作。研究活跃程度依据连续进展、基准演变、实际需求与尚未解决的问题判断，不按网络名称新颖、论文数量或刊物声望排序。

产出一张领域问题图：哪些任务已有成熟做法，哪些只在限定假设下成立，哪些仍缺数据或可检验定义。把作者主张、实验实际支持的范围和我们的判断分开。关键文献标出实际阅读范围：摘要、指定章节、全文、代码检查或结果复算；不能以下载数量代替阅读深度。

## 第二步：把大方向拆成具体场景与科学问题

逐个场景连贯回答：

> 谁观察或研究谁 → 实际能获得什么信息 → 要判断或解释什么 → 为什么难以判断 → 已有研究怎样解决 → 还缺哪一项证据或能力。

场景应由对象、环境、观测条件或决策任务区分，不以算法家族代替场景分类。先考察整个方向，再比较适合推进的场景；当前最熟悉的场景可以重点展开，但不能替代对其他候选场景的核查。

随问题解释必要的领域知识：哪些物理、实验、临床或社会机制决定输入与标签，哪些约束影响可识别性，哪些误差改变结论。统计推断与人工智能方法则说明具体作用、前提与替代方案。知识清单必须能对应一个待解决的问题，避免先列一整套课程或算法名词。

这一阶段应能写出一句可检验的问题：在明确条件和可用信息下，判断什么，与什么成熟做法比较，通过什么观测区分竞争解释。若只能说“提高智能化水平”，还没有细化到可研究的问题。

## 第三步：逐篇核清数据从哪里来、如何处理、能证明什么

以代表论文为单位建立证据链，再比较不同论文。至少核清原始观测、加工产品、仿真或混合数据的区别，以及对象数量、独立样本单位、时间跨度、采样、缺失、标签依据。处理过程追到坐标与时间、单位转换、滤波或插值、特征构造、归一化和训练测试划分。没有报告的字段写“未报告”，不要根据通行做法补写。

重点检查判断时刻是否能得到输入，是否使用未来信息，同一对象、原始事件、生成条件或数据变体是否跨越训练与测试。说明标签直接证明什么、哪些更强解释仍需外部证据。具体准入与隔离规则见 research-execution 技能的数据准入与知识隔离一文，单篇记录直接引用原有阅读笔记。

**数据、代码、模型权重、生成器分别登记公开状态**，并附来源、版本、许可及核查日期：

| 状态 | 使用边界 |
| --- | --- |
| 可直接获取 | 有可访问的公开入口；是否已完整下载和核验另记 |
| 注册或申请后获取 | 写明条件、申请入口及当前获得权限的情况 |
| 仅公开部分 | 指出公开了哪一部分、缺少什么 |
| 作者明确不公开 | 引用作者或机构的明确说明 |
| 未找到公开说明 | 说明已检查的来源，不能据此断言不公开 |
| 链接当前不可访问 | 记录作者公开声明、链接、日期与访问结果，不改写为作者不公开 |

论文公开不等于数据公开；能够下载不等于允许再分发；没有找到许可时如实记录。状态描述的是核查时点的证据，不是永久属性。

## 第四步：重建方法、核对创新，并判断推进条件

选取每个场景的代表方法和直接竞争方法，讲清完整技术过程：

> 输入 → 领域机制或物理建模 → 推断或学习过程 → 输出 → 对照实验 → 结果与局限。

解释方法为何可能解决该场景的困难、哪些模块提供了新信息、哪些只是实现选择。分别写清作者声称的创新、实验支持的增量，以及我们认可或仍存疑的部分。成熟简单方法、领域强基线和最直接的新方法应进入比较；消融不能替代有竞争力的外部对照。

资源分成训练、推断和数据准备：硬件、内存、时长、仿真工具、数据权限、标注劳动、外部服务与成本。作者报告、我们的实际条件和估算分别标记；未报告的内容留缺口，估算注明依据，不能把自己的设备写成论文配置。

预期效果写成可检验目标，例如在相同误警水平下缩短识别延迟，或在固定预算下减少错误排除真实解释的风险。没有实验证据时不预填提升比例。列出最小验证、可能的失败结果，以及何时应调整问题、保留简单方法或放弃候选机制。

## 收束：对照研究储备，把候选想法解释到可取舍

先重建研究推进过程，再判断下一步。每个阶段说明考虑过什么、依据什么调整、完成了什么、结果支持什么、留下什么可沿用基础。原始会话证明讨论和决定发生过；代码、数据与结果支持实际完成程度。时间顺序和版本必须核对，早期准备索引不能覆盖后来已完成的实验，后来的总结也不能抹去早期有效分析或负结果。

候选想法保留原编号、提出过程及后续修订。逐项交代以下内容，篇幅随成熟度分配：

1. 来源：哪次讨论、哪篇文献或哪个实际困难；链接到原话或原始材料。
2. 场景与问题：它解决四步调研中哪一个具体缺口。
3. 技术过程：输入、输出、主要步骤，领域知识和统计或人工智能方法各起什么作用。
4. 竞争方法与可能价值：相同条件下为何可能增加信息或改善决策。
5. 前置条件：数据、权限、算力、工具、标注与需要先完成的工作。
6. 当前成熟度：已完成工作、实际结果、尚未检验的设想分别说明。
7. 验证办法：比较对象、指标、独立单位、划分与必要反例。
8. 取舍条件：什么结果支持继续，什么结果要求调整或放弃。

区分科学问题、方法模块、实验设计与工作流程，不把全部想法包装成同等成熟的论文课题。工作流程可以帮助研究，但其部署成功不证明科学方法有效。候选数量不设门槛，来源案例中的18项不是通用要求。

最后给出有依据的优先课题、备选课题与暂缓项。每项指出尚缺的判别条件，证据不足时保留未定题状态。学习路线从拟推进问题倒推，每个学习主题对应一个可检查产出，如解释观测链、重建基线或检查标签；不以学完所有方法作为开始研究的前提。

## 怎样写成可汇报、可接续的材料

较长的进展与选题报告，可用开头一至两页回答“方向研究什么、我们做到哪里、优先继续什么、还缺什么”，再按问题展开证据。是否采用两页由用途和篇幅决定。报告文体、语言和图表遵循 report-writing 技能的非论文报告写作规范（R1—R5），不把核查清单机械改造成重复段落。

整理记录时沿用已有正式记录库，以问题连接文献、讨论、决定和结果；原始消息保留身份、时间、顺序与来源。原始文献、数据、代码继续使用正式目录，通过链接导航。新写说明使用完整专业名称；原话按原样保存。材料缺失、无法访问及尚未核验的内容单独列明。

完成标准是读者能从一个具体问题追到原始证据，理解方法与资源要求，分清已经做过和准备做什么，并知道下一项证据会怎样改变选题。空白记录使用[研究问题与文献卡](../templates/研究问题与文献卡.md)。本方法不自动启动新实验，也不替代正式实验协议。
