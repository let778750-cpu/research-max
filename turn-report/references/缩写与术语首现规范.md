# 缩写与术语首现规范

本文件是 T7 与 TD8 的执行细则：大写字母缩写第一次出现怎么写、什么时候可以不写缩写、全称不知道怎么办、术语怎么统一。病灶分级见[过度防御表述诊断与改写](过度防御表述诊断与改写.md)第五节。

## 一、三种合法写法

缩写首次出现时，按下列任一种写；同一篇内只选一种，不混用：

| 写法 | 示例 | 适用 |
|---|---|---|
| 中文名（English Full Name, ABBR） | 混合整数线性规划（Mixed-Integer Linear Programming, MILP） | 默认，中文正文 |
| English Full Name (ABBR) | Mixed-Integer Linear Programming (MILP) | 全英文段落、字段说明 |
| 中文名（ABBR） | 混合整数线性规划（MILP） | 只在英文全称确实无处可查、且该缩写已属领域通用时；并在首次出现处标"全称待核" |

此后全文统一用缩写，不再重复展开。同一篇里同一缩写只定义一次。

## 二、什么时候必须展开，什么时候可以不用缩写

- 首次出现于标题、摘要、结论句、图表标题：必须展开，或干脆不用缩写。
- 只出现一两次、且不承载判断：直接写中文全称，不造缩写。缩写是省字工具，不是专业感装饰。
- 跨段落反复出现、且读者需要回查：展开一次，并登记到项目术语表。
- 引用他人定义：按原文写法，首次给出处；改写原文定义时标明"按本文用法"。

## 三、白名单：不强制展开的类别

| 类别 | 例子 | 说明 |
|---|---|---|
| 计量单位 | MB、GB、Mbps、ms、km、Wh、° | 单位符号不是术语缩写 |
| 文件格式与扩展名 | PDF、CSV、JSON、PNG、MD | 作为文件名或格式名出现时 |
| 代码标识符、路径、命令 | `pkg.contracts`、`--strict`、`python` | 已在代码区内，读者按代码理解 |
| 公司、产品、标准专名 | 具名产品、标准编号如 WGS84 | 专名按官方写法 |
| 领域内已属公认定名 | 由项目术语表登记，且首次出现仍给中文名 | 登记是前提，不是豁免 |

白名单只解决"不必展开"，不解决"可以用错"。同一缩写在本项目内只能有一个含义。

## 四、全称不知道怎么办

- 写中文名，标"全称待核"，并在边界段说明缺什么。
- 禁止臆造英文展开词：编一个像样的全称比不写更糟，读者会当真。
- 禁止把缩写当动词或形容词生造用法（如"已 MILP 过"）。
- 已知缩写但不确定是否同一概念时，写"按 A 文献的用法"并给出处，不做合并。

## 五、一次性与登记

1. 同一篇内首次出现展开一次，之后只用缩写。
2. 项目术语表设"英文/缩写"栏，新缩写在首次使用同轮登记，供他人回查。
3. 同一项目多份文档共用一个缩写表；不在每份文档里各造一套。
4. 缩写在图表标题、表注中单独出现时，表注内再展开一次，不指望读者回翻正文。

## 六、与术语一名制的关系

- 同一概念只用一个中文名；缩写是该中文名的可选简写，不构成第二个名字。
- 不用缩写轮换指同一概念（如正文写"调度器"、图注写"SC"、结论写"scheduler"）。
- 代码字段保持英文原样，正文不复述字段名。

## 七、六类常见错误

| 错误 | 表现 | 改法 |
|---|---|---|
| 首现不展开 | "MILP 给出 35 单" | 首次写全称加缩写 |
| 重复展开 | 每段都写"混合整数线性规划（MILP）" | 只首次展开 |
| 臆造全称 | 为凑格式编一个英文名 | 标"全称待核"，不编 |
| 缩写当动词 | "先 LNS 一遍" | "先用大邻域搜索（Large Neighborhood Search, LNS）重排一遍" |
| 一缩写多义 | 同一文档里 LNS 既指方法又指模块 | 拆成两个名字，一个概念一个名 |
| 标题堆缩写 | 标题写成"XXX 的 MILP-LNS 联合框架" | 标题写中文名或不写缩写 |

## 八、对照

| 原写法 | 改写 |
|---|---|
| MILP 在 12 秒内返回可行解。 | 混合整数线性规划（Mixed-Integer Linear Programming, MILP）在 12 秒内返回可行解；MILP 只覆盖已枚举候选。 |
| 先用 LNS 重排，再回放校验。 | 先用大邻域搜索（Large Neighborhood Search, LNS）重排，再用同一回放器校验。 |
| 结果写入 JSON，字段见 API 文档。 | 结果写入 JSON（JavaScript Object Notation，JSON 格式，作为格式名不展开）；字段见接口文档。 |
| 该指标用 MAE 衡量。 | 该指标用平均绝对误差（Mean Absolute Error, MAE）衡量。 |
| CRC 校验失败 3 次。 | 循环冗余校验（Cyclic Redundancy Check, CRC）失败 3 次。 |
| 图结构用 GNN 编码。 | 图结构用图神经网络（Graph Neural Network, GNN）编码。 |
| 详见 RTK 结果。 | 详见实时动态定位（Real-Time Kinematic, RTK）结果；全称待核处按此写法登记。 |
| SNR 低于下限时剔除。 | 信噪比（Signal-to-Noise Ratio, SNR）低于下限时剔除。 |

## 九、检查

`reply_lint.py` 的 TR7 只查一件事：大写串首现是否在附近有全称定义。它不判断全称真假，也不判断缩写是否属于白名单之外的新概念——这两件事由人和项目术语表负责。已知白名单可用 `--allow` 追加文件，一行一个缩写。
