# 逐轮任务汇报技能

自包含技能，随 research-max 技能集分发使用。管的是 Agent 每轮任务结束、把结果交给用户时的那段话：先给判断，再给证据，边界一次说完，缩写首次出现给全称。论文成稿与非论文文档的正文写作按 paper-writing 与 report-writing 技能，不在本技能内。

| 目录 | 内容 |
|---|---|
| [references/](references/) | 规则全文：过度防御表述诊断与改写、结论优先汇报结构、缩写与术语首现规范 |
| [templates/](templates/) | 空白模板：汇报自检卡（写后对照，逐项判通过或不通过） |
| [scripts/](scripts/) | reply_lint.py 本地机械自检（结论行、免责分布、空泛词、锚点密度、缩写首现）、默认白名单 allowlist.txt 与自测；不联网、不调用模型。自测：`python -m pytest scripts -q` |

## 七条要求（速览；执行读 references 原文）

**T1 判断先行**：首段不超过五行，回答"做了什么、结论是什么、能不能用"；首句不是导览。

**T2 证据锚点**：每条结论至少一个可定位锚点——`文件:行`、数值与单位、命令、结果路径、测试或回放名。无锚点的判断自标"推断"或"设计层"。

**T3 边界集中**：局限、未做、未验证、外部依赖合成一段，固定标题"边界与未做"；同一免责全文只出现一次。

**T4 强度校准**：措辞强度跟证据强度走，五档映射见诊断文件；既不升格也不降格。

**T5 去模板**：删开场套话、自我导览、结尾软化与空泛抽象词；一段一个判断。

**T6 篇幅守恒**：以判断条数为分母，一条判断不超过一百二十字；无新判断不扩写。

**T7 缩写首现**：写"中文名（English Full Name, ABBR）"，此后统一用缩写；全称未知标"全称待核"，不臆造；单位、文件格式、代码标识符与产品专名除外。

## 场景流程

| 场景 | 做法 |
|---|---|
| 短问答、单点确认 | 一句判断加一行依据；不铺背景，不加免责尾巴 |
| 单文件或单命令改动 | 判断、改了什么（路径与行号）、怎么验的、边界 |
| 多文件、实验或长排查 | 判断、三到六条判断各带锚点、边界与未做、下一步（有具体动作才写） |
| 失败、回滚、未完成 | 先写"没做成"或"回滚了"与原因，再写证据与下一步；不把失败包成"存在差异" |
| 落盘报告或长说明 | 按上述结构写完后运行 `reply_lint.py --file`；警告人工复查，失败不得交付 |

## 交付闸门

1. 自检卡十项逐项过，不合格项先改再发。
2. 长汇报或落盘稿运行 `python scripts/reply_lint.py --file <草稿>`：退出码 0 通过、1 警告（人工复查）、2 失败（不得交付）。
3. 机械通过不等于表达合格：脚本只数结构信号，判断是否成立仍看证据。

## 贯穿红线

- 压缩的是重复免责，不是不确定性：限定条件、单位、版本、失败与负结果、未做声明一律保留。
- 不虚构数据、命令输出、验证或经历；没跑的写没跑，没读全文的写没读全文。
- 不为"像人写的"制造参差、删条件或改写结论；本技能不针对 AI 检测器。
- 缩写服从可回查：全称未知就写中文名并标待核，禁止编造英文展开词。
- 汇报对象是同行：术语一名制，数值带单位，时间基准与参照系等计算前提首现写清。

## 边界

- 期刊会议稿件按 paper-writing 技能（含成稿去 AI 味分级清理），非论文文档正文按 report-writing 技能；本技能只管"把结果交给用户的那段话"，不改研究内容与文档正文。
- 不做作者归属判断，不据文本特征断言是否由 AI 写成；只判结构缺陷。
- 脚本只在本地读文件，不联网、不调用模型、不付费；机械通过不代表实质审查通过。
- 规则在本目录单一维护；跨技能只按名提及，不复制副本，也不做跨目录链接。
