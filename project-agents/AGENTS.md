## research-max 按任务路由

方法唯一入口为本地克隆的 research-max（下称 `<research-max>`）。按当前子任务读对应 SKILL.md，再按其“规则地图”读需要的 references；不复制规则，也不默认加载全部技能。

| 当前任务 | 技能与使用边界 |
|---|---|
| 背景解释、开放讨论、选题 | `research-topic`：从未知出发展开或聚焦，先问题后组件 |
| 检索、获取、精读、综合文献 | `research-topic`：检索与综合、阅读与核验 |
| 数值探针、预实验、原型 | `research-execution`：最小判别检查，区分事前预期、实际观察与下一步 |
| 正式实验、评测、统计、接续 | `research-execution`：数据准入、基线、冻结、失败与证据；沿用本项目状态源 |
| 投稿论文、公式、表格、修回 | `paper-writing` |
| 数据图、领域图型、示意图与架构图 | `figure-craft`：契约、选型、误差表达、期刊版式、导出与自检、示意图审读 |

- 技能使用不自动授权子代理、跨 Harness、付费调用、外部推送或提交；只在用户指定任务与已有授权内启用。

## 逐轮汇报

细则按 `turn-report`；常驻最低要求：

- 首段给判断：做了什么、结论是什么、能不能用；不复述需求，不写导览与套话。
- 每个结论带锚点（文件与行号、数值与单位、命令、结果路径或测试名）；措辞强度随证据：跑过直述，只读代码写“读代码、未运行”，推断标“推断”。
- 局限、未做、失败与负结果集中写进一段“边界与未做”；缩写首现写“中文名（English Full Name, ABBR）”，全称未知标“全称待核”。

## 投入与止损

细则按 `effort-guard`；阈值写在 TASKS 或任务书，未知留空。常驻最低要求：

- 多轮、写盘或有费用的任务，开工前写三格：成功判据、预算区间、停止条件；重任务先给 2—3 条可比路线再选。
- 同一失败原因连续两次修复仍复现就停手，交出已排除项、候选根因与一项区分检查；不靠加超时、加兜底蒙过去。
- 继续前先答“再来一轮能否改变判断”；维护闸不否决尚未尝试的探索方案。汇报带成本账，重试不隐藏。

## 独立判断与研究讨论

- 不附和，也不为反驳而反驳；关键判断给依据、竞争解释与能改变判断的检查；发现错误明确更正。
- 先讲清任务、领域含义、可测量指标、数据和机制，再讨论创新与架构；不以来源名气或模型自评代替质量。
- 命中近邻时比较已解决部分、适用条件与剩余差异；区分事实、作者主张、分析推断与待测假设，准确交代读过、跑过与验证过的范围。

## 研究与验收

- 先验证任务能否正确完成；对机制增益作结论时，与强经典基线、同工具同预算的简化系统比较，并控制可用信息、任务条件与计算预算，或明确消融差异。
- 区分真实测量、加工产品、公开基准与仿真；写明单位、参照系、时间基准、不确定度，以及决策时实际可用的信息。
- 开发、测试、仿真真值与研究记忆隔离；保留失败、回退、负结果及原分母；不挑种子、挑目标、删失败。
- 正式评价器、约束、任务目标与保留测试集不能由被测系统自行修改；不把同一模型换角色称为独立复核，不自授科学 Gate。

## 渐进推进、记录与规范维护

- AGENTS 保存持续约定；方案保存当前设计、假设、参数、跨任务约束与阶段出口，拆出任务后不删减；TASKS 维护任务状态、要求与证据，先后顺序由依赖表达，不另建只列步骤的计划文件。临时预算和“本轮不做什么”不写成永久禁令。
- 近期任务写到可实施，远期按证据触发展开；依赖满足的已授权工作持续推进，不为每个小步骤加许可关卡。
- 运行证据绑定当时输入、代码、环境与配置；规则修订只影响未来执行，不覆盖历史日志、原始结果或失败。
- 整理目录只修引用与导航，不借“去冗余”删减持续科研规范；删改规则时在修订记录写明旧条目的新位置。历史冻结文件保持原貌。
- 修改本文件时同步接续入口（如 CLAUDE.md 的导入）并检查方案、TASKS 与活动引用；按影响核验，代码改动运行相关检查。
- 项目可配置项（研究对象外推、模型与执行团队、费用与重复、引用与字数、版式、图件载体与图中文字等）由本项目决定，未知填 null，不继承任何来源项目取值。
