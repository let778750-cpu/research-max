# 范文拆解与句式学习卡

按[W9范文拆解与句式迁移](../references/论文组织与语言规范.md#范文拆解与句式迁移)使用。本卡只记录一次练习及其证据，填写项保持空白；原文摘录、自写内容和实际研究发现分别标识。

## 来源与选择

- 练习目标、日期与记录者：
- 范文标题、作者、年份、文章类型及版本：
- DOI或稳定地址、访问日期：
- 本地原文位置及SHA256：
- 目标研究、目标文章类型、期刊或读者：
- 选择理由；相适配之处与不可迁移之处：
- 用途：科学引用、方法复现或表达学习；分别核验的状态：
- 本次分析的章节、段落、句子及页码：

|---|---|---|---|---|---|
| | | | | | |

## 句式学习条目

- 学习条目标识及来源定位：
- 短摘录（如保留，注明是原文及使用依据）：
- 所要实现的沟通功能：
- 提炼的通用骨架与可替换槽位：
- 适用条件与不适用情形：
- 表达的确定程度；需要什么证据：
- 支撑自写版本的本研究材料位置及版本：
- 离开原文后形成的自写版本：
- 需要在实际稿件引用的事实、方法或观点及其来源：

## 对照、批判与修订

- 范文的证据或表达缺点：
- 自写版本遗漏的条件、数字、单位、否定或结论边界：
- 是否沿用了独特表述、他人论证或发现；处理位置：
- 采纳与放弃的写法及理由：
- 修订后的自写版本：
- 实际稿件使用位置、版本与核查记录：
- 下一项练习或补证行动；本次仍待核实的事项：
