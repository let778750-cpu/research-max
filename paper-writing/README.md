# paper-writing：论文写作经验规则技能

面向领域科研人员的论文写作规则库，提炼自 AI 辅助科研的实战经验，覆盖从起草到交付的完整写作链路。目标是让稿件经得起同行审查：研究问题清楚、证据可追溯、表达自然具体、版式符合真实投稿模板。

## 适用范围

- 期刊/会议论文稿件：起草、逐章写作、修改润色、公式与引用、图表与版式、附录与补充材料、交付自查、审稿回复
- 实验型与方法型研究论文；综述、纯理论文章按职责调整结构
- 不适用：非论文报告与记录、研究流程管理、投稿系统操作

## 目录结构

```
paper-writing/
├── SKILL.md          # 技能入口：规则地图、写作流程、贯穿红线、交付闸门
├── references/       # 规则全文
│   ├── 论文组织与语言规范.md   # W1—W10：主线、题名、引言、原理、方案、结果、讨论、摘要、语言、修订
│   ├── 公式与引用规范.md       # M1—M4：符号单位、公式推导、证据引用、文献排布
│   ├── 科研图表与模板验收.md   # F1—F7：图表设计、确定性结果图、图源、三线表、图表解读、版式、中文PDF验收
│   ├── 科研绘图生产规范.md     # F8—F14：图形契约、图型四原型、配色无障碍、字号线宽刊印、多面板、导出、渲染后自检
│   ├── 附录与补充材料规范.md   # A1—A7：必要性、载体、分配、组织、定位、一致性、交付
│   ├── 投稿与修回.md           # 投稿前核对、审稿意见路线图、回复信结构与覆盖度自审
│   └── 偏好表示例.md           # 个人化样式条目的记录方式（示例值，非通用规定）
├── templates/        # 写作空白模板：正文与附录规划、稿件审查单、范文拆解与句式学习卡、图形规格卡与绘图样式示例、审稿意见路线图
│                    # （主张与证据表、交接与修回、submission_profile.json 随 research-execution 技能分发）
└── scripts/
    └── writing_lint.py  # 写作质量机械自检：节奏 / 内容守恒 / 中文PDF排版
```

## 使用方式

**AI 助手**：从 `SKILL.md` 进入，按当前任务在规则地图中选择对应规则文件，按需加载。

**人工使用**：直接阅读 `references/` 下的规则文件；交付前用 `templates/稿件与图表审查单.md` 做三遍检查，并运行：

```powershell
python .\scripts\writing_lint.py rhythm  <稿件.md>
python .\scripts\writing_lint.py parity  <原稿.md> <新稿.md>
python .\scripts\writing_lint.py layout  <成品.pdf> --right <版心右缘pt>
```

`writing_lint.py` 只用本地文件，不联网、不调用模型；layout 模块依赖 [PyMuPDF](https://pymupdf.readthedocs.io/)（`pip install pymupdf`），建议设置 `PYTHONUTF8=1`。判定两级：警告＝提示人工复查，失败＝按规则不得交付；通过只代表机械项通过，不替代科学内容审查。

## 核心立场

- 科研真实性不可妥协：润色不替代补证，负结果如实入账，不虚构数据、引文与审稿对话
- 写作者是领域科研人员，AI 是方法中的具体能力，不是研究目的
- 定量结果图由确定性数据生成，版式验收以文本提取为准
- 规则阈值（如段落节奏量化参考带）为初版标定，随使用修正

本技能的写作规则自包含，随 research-max 技能集分发；规则细节在各文件内单一维护。项目级共享模板（主张与证据表、交接与修回模板、submission_profile.json）的唯一权威在 research-execution 技能，本技能按名使用、不复制副本。
