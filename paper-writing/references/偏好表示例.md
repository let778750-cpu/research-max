# 写作与版式偏好表（示例）

本表是一份真实项目偏好表的**示例**，展示需要个人化决定的条目和记录方式；具体值来自该项目，不是所有刊会或作者的统一规定，新项目按当前用户选择与实际模板重新填写。科研论证与语言规则统一见[W1—W10](论文组织与语言规范.md)，不在这里另抄一遍。

| 项目 | 本轮已确认的要求 | 执行边界与核查位置 |
|---|---|---|
| 叙述立场 | 站在懂AI的航空航天科研人员视角，重点解释航天问题、动力学及工程含义 | 泛化为“本领域科研人员视角”；不能仅将AI行话替换成航天名词 |
| 章节安排 | 范围说明并入引言；原理、数据与方案、结果分别展开；讨论与结论合章 | 小节按完整论点划分；其他模板可调整编号和章节形式 |
| 题名 | 兼顾科研场景与大模型，精炼且与全文研究一致，避免过细模块堆砌 | 只有实际研究包含相应方法与证据时才进入题名 |
| 正文自足 | 主文说清核心原理、方案、指标和发现，不用“见补充材料”回避 | 复杂细节可概括，不能省略影响结论的假设与评价定义 |
| 篇幅 | 原论坛稿目标6000—8000字 | 单独报告正文和全文口径；以该项目附件及用户最新要求为准，不用拉长背景凑字 |
| 段落 | 一个段落完成一个意思，长短自然变化 | 不刻意等长，也不随机拆合；执行W9 |
| 中西文间距 | 中文正文相邻的汉字与拉丁字母之间不人为留空格 | 不破坏英文词间空格、数值与单位的规范间隔、公式间距及网址 |
| 稿件源 | 当前论文先修完整LaTeX源，检查通过后制作DOCX和PDF；Markdown保持对应 | 这是对早期“Markdown先行”的后续明确修订；新项目先确定权威源，不维护多份独立正文 |
| 数学对象 | 正文所有数学表达采用真实LaTeX语法，Word中保留可编辑公式 | 不能以公式截图、近似字符或公式数量相同代替内容一致 |
| 图像格式 | 当前论文直接使用PNG，不擅自转SVG | 结果图保留确定性绘图脚本；若新投稿渠道另有硬要求，明确差异再处理 |
| 概念图生成 | 可用当前图像工具并记录实际来源，不冒称image2.5 | 替代服务已获本轮授权；模型身份、字体和原生分辨率仍按实际记录 |
| 图中文字 | 中文宋体，英文和数字Times New Roman；描述精炼，不用斜杠拼接标签 | 例如“假设与工具选择”；单位优先用规范指数形式。位图外观不能认证原字体文件 |
| 图件尺度 | 按最终刊印尺寸检查；本项目图中文字约9磅，必要栅格线图目标至少600dpi | 核查实际像素和排版宽度，不把修改dpi元数据或上采样称为原生达标 |
| 图表正文 | 每图每表前有精炼引入，后有充分解释；涉及数据则说明具体比较 | 方法见F5；“详细”指论证充分，不逐格朗读 |
| 三线表 | 内容与数值规范，列宽按信息分配，避免表4式末列大块空白 | 表宽、换行和小数对齐以实际渲染检查；不固定复用旧表列宽 |
| 正文引用 | 引用序号紧贴对应文字右上角，位于标点左侧 | 顺序为“文字—上标序号—标点”；不能排成正文基线或标点之后 |
| 作者和单位 | 中英文姓名顺序一致，单位编号正确上标，单位全称、城市及邮编完整 | 模板示例信息仅为经授权的草稿占位；投稿前替换并核实 |
| 首页下方信息 | 按附件排第一作者简介及基金，含分隔线、缩进和字号 | 简介包含模板所需出生年、性别、学位、职称、方向和邮箱；不编造真实身份 |
| 偶数页页眉 | 按附件在左上角排指定论文编号或标注 | 模板示例编号不视作主办方实际分配编号；核对位置与版心 |
| 偶数页页脚 | 页码靠左，并与正文版心左边界对齐 | 同时分别检查首页和奇数页，不能用一套全局页脚代替 |
| 正式PDF | 从最终DOCX导出并逐页查看 | LaTeX预览用于检查源稿，不能冒充最终Word版对应PDF |

落到项目时，将具体值、附件位置及核查状态写进项目根目录的`submission_profile.json`（空白模板随 research-execution 技能的项目骨架分发）。未知项保留待核实，不用别的论文补空。审查对象始终是当前实际提交版本。
