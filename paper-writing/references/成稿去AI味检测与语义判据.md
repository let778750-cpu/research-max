# 成稿去AI味检测与语义判据

本文件是W9[结构与节奏的模板化控制](论文组织与语言规范.md#结构与节奏的模板化控制)的执行细则：正文完成、内容稳定后的成稿清理怎么检、怎么判、怎么改、怎么复测。哪些写法算AI味、哪些已否决，以[论文组织与语言规范](论文组织与语言规范.md)为单一权威，本文件不另立规则；改写纪律（最小改动、信息守恒、不制造参差、结构不动）见其W10节。

## 三层分工

| 层 | 管什么 | 谁执行 | 载体 |
|---|---|---|---|
| 脚本层 | 数得出符号的：固定句式、标点密度、结构指标 | [ai_tone_detect](../scripts/ai_tone_detect.py)（本地运行，不联网、不调用模型） | 分级候选数据 |
| 语义层 | 要理解句意的：同义重命名、衔接连环、冒号分类、同构三连 | 会话内模型按本文件封闭判据逐条判 | `--candidates`抽取候选，判后写回JSON |
| 人审层 | 机器间共识不够的：比喻贴切度、暗喻、拟人化喻体 | 用户 | 默认保留不扫描；主动要求时只列出不评级 |

脚本输出是候选数据，不是结论；模型逐条复核后向用户交报告，命中清单不静默删项。检测目的先于改写：AI味的大部分特征是分布特征，单看一处看不出来，也不该逐处改；先交有指标、例句和改法的报告，等用户回复再动手，是防过度清理的闸门。

## 分级口径

分级看改动风险（改这一处会不会碰到语义、要不要补信息、会不会越界），不看特征强度：

| 级 | 含义 | 策略 |
|---|---|---|
| A 机械改 | 固定句式／标点问题，改动不触碰语义 | 模型复核误报后列入拟改 |
| B 建议改 | 需句式重组或换说法 | 逐条筛选，报告典型例句与改法 |
| C 只报告 | 结构／节奏类整篇分布特征 | 默认不改；用户要求时再处理，不追求推到目标值 |
| X 已否决 | 实测不是AI味（W9已否决特征清单） | 永不改；报告标出只为防误改 |
| F 指纹 | 分模型特征（破折号、分号、引号等） | 可定位且能安全改写的默认拟改，保留需说明该处具体作用；密度只用于排序优先级 |
| H 人审区 | 模型判不准贴切度的 | 默认保留；用户主动要求时列清单，不评级不给意见 |

## 工作流（按顺序）

1. **脚本检测**（改前务必`--json`存档，第5步对比要用）：

   ```
   python scripts/ai_tone_detect.py <稿件.md> --json > 改前.json
   ```

2. **语义层判读**（单篇必跑）：

   ```
   python scripts/ai_tone_detect.py <稿件.md> --candidates --out 候选.json
   ```

   对抽取的四类候选（同义重命名段／段间接口／冒号句／三连同构组）按本文件判据逐条给出`label`／`confidence`／`reason`写回JSON，再按汇总口径算四个数。

3. **改前报告**：按[成稿去AI味检测报告模板](../templates/成稿去AI味检测报告模板.md)交付——本篇指标与命中去向（原始命中数、有效命中数、拟改数、保留数）、例句与改法、排除项与理由。明确区分"研究语料中的统计显著"与"本篇单次命中"：单篇未做显著性检验，不得宣称本文统计显著，更不得据此断言作者是AI。报告是唯一的改前确认点，收到用户回复前不得改写正文。

4. **改写**：只改用户接受或调整后纳入方案的项；每处改动记录"原文→改后＋所属W9条目"，遵守W10六条纪律。用户回复"按建议改"即执行，不二次确认；只提问或要求暂缓则先回答或暂停，不把沉默当同意。

5. **复测与前后对比**：

   ```
   python scripts/ai_tone_detect.py <改后.md> --json > 改后.json
   python scripts/ai_tone_report.py <原稿.md> <改后.md> 改前.json 改后.json --semantic 判读后.json --out 清理报告.md
   ```

   复测判读：拟改的A/B/语义/F局部命中应完成修改；标题、清单等误报保留并在报告说明；F指纹密度变化给方向解读，不强迫归零；C级结构指标（句长CV等）给数字但不追求推到目标值——把句长CV从0.37拉到0.67是机械参差化，比不改更糟。

执行倾向：有效且可定位的命中默认拟改；"保留"需逐处举证（该处修辞、引文、术语、语义关系或作者风格为何不可替换），不能只写"读着自然""只有一处"；判不准标"待核"，不归零。

## 学术文体排除

以下内容不进入检测与计数：代码块与行内代码；公式与数学推导；引文原文（任何情况下不得改动引文本身）；图表题注与图表内文字；参考文献条目；术语首次引入的定义句（含"又名／记为X"的正式介绍）；刊会模板规定的固定结构（编号小节、结构式摘要栏目标签、模板句式）；独立成段的英文摘要。

## 语义层判据（四项，封闭标签）

判断纪律：只按判据判，不按"像不像AI"的整体感觉判；每条独立判断，不看全文来源；拿不准选兜底标签（无法判断类）；标签只能从判据集合中选，禁止自造。

### 1. 同义重命名（段级）

对每段数"换实义说法"的等同连接次数（代词、省略不算）：

| 标签 | 判据 |
|---|---|
| 0组 | 段内每个实体／概念自始至终同一（或字面几乎相同）说法，或只出现一次 |
| 1组 | 一个实体／概念在段内换了1次实义说法，读者需做1次"X即Y"连接 |
| 2组 | 两个实体各换说法，或同一实体换了2次 |
| 3组及以上 | 换说法的连接达3次或更多 |
| 无法判断 | 段落无法分析 |

学术适配：同一指标因语法位置不同而变形（如"该方法／本方法"）按换说法计；不同实体恰好用近义词、术语首次引入的正式介绍不算。

### 2. 衔接方式（段间接口）

对每个段间接口（上段末句→下段首句）判衔接方式；下句首有连接词时，先核对其标示的逻辑关系是否真的成立：

| 标签 | 判据 |
|---|---|
| 表面有连接词实际关系不清 | 连接词（但是／因此／于是等）标示的逻辑关系不成立或勉强——优先检查 |
| 明确承接 | 围绕同一对象或论述关系自然继续，允许同义词、代词、省略；有连接词且逻辑确实成立 |
| 有关但转换突然 | 同一话题域但衔接突兀，缺一步过渡，读者需自行补跳过的逻辑 |
| 主题跳转缺少说明 | 换到基本不相关的新话题且无衔接说明 |
| 无法判断 | 上下文不足 |

统计口径：连续"明确承接"的接口数为连环长度，≥6连环即报告。改写只选一两个接口改自然跳跃；先检查该接口是否承担因果或伏笔功能，承担则换下一个。

### 3. 冒号分类（正文冒号句）

按优先级从上往下判，命中即停：

| 标签 | 判据 |
|---|---|
| 引语或人物发言 | 冒号前是人名／称呼＋发言格式，或有"说／表示／提出"等引出词紧跟人物主语（最优先） |
| 版式或元数据用途 | 冒号前是标题结构、时间戳、比例、来源作者等元数据 |
| 定义或解释 | 冒号前是术语／概念／功能名称，冒号后给其定义或具体内容 |
| 空转提示 | 冒号前只是空洞宣布"下面有几点"，不含论断，冒号后纯列举——**已否决项，不改** |
| 结论提示 | 冒号前是独立、明确的结论性判断（含"是／在于／取决于"等论断谓语），冒号后展开论证——**唯一真信号** |
| 其他正文冒号 | 不属以上任何类，默认落点 |
| 无法判断 | 上下文不足，不滥用 |

### 4. 高度同构三连

只判一组三句，不给全文：

| 标签 | 判据 |
|---|---|
| 高度同构 | 三句的主谓宾及补充成分位置基本一一对应，句法框架几乎相同，只是填入的词不同 |
| 部分同构 | 结构明显相似但只部分对应，或多出／缺少成分 |
| 只有词语重复句法不同 | 重复了某些词或短语，但整体句法组织不同 |
| 只有语义并列句法不同 | 内容上构成并列，句法结构不同 |
| 无同构关系 | 句法与语义并列均无明显对应 |
| 无法判断 | 上下文不足或句子残缺 |

与顿号罗列分界：顿号管句内塞多项，本条管句间共用骨架。改法是拆掉其中一句（合并、拆分、换语序或改短句），不是删掉一项内容；刻意修辞、清单表格体、叙事推进的三件事不算。

### 汇总口径

| 指标 | 计算 | 人类参考 | 报告门槛 |
|---|---|---|---|
| 同义重命名 次/段 | 各组标签数之和／段数 | 约0.49 | ≥0.7，或重灾段（≥2组）占比>15% |
| 衔接连环 | 最长连续"明确承接"接口数 | 中位约2 | ≥6连环 |
| 结论冒号占比 | 结论提示／正文冒号总数 | 低基线 | 相对比例高即列B级 |
| 高度同构三连数 | "高度同构"标签计数 | 低基线 | ≥2组即列B级 |

四项参考值来自通识中文语料的两轮实测，学术论文语料未重标定，作初版参考随使用修正；证据登记见SOURCES.md。

## 报告与复测口径

- 命中去向完整：原始命中→有效命中→拟改→保留的差额都有记录；语义判读阴性（不符合判据）也是计数的一部分；不把不喜欢的候选移出清单。
- 整篇分布指标（句长CV、结构方差等）只报实测值与处置，不强造逐句命中数，不假装成某句的错误。
- F级指纹是模型使用偏好，不能反推本篇由哪个模型写成；不要求用户提供生成模型，未知来源文本照常检测，报告只说方向相似性。
- 复测后X级特征应保持原样；发现被误改（如删了"本文贡献如下："引举、改了编号小标题）按误改回滚。
