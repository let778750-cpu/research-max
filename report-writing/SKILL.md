# 非论文报告写作技能

自包含技能，随 research-max 技能集分发使用。覆盖投给导师、课题组或合作者的报告、记录、评审意见：先判断文体，再按本技能组织表达。科学要求不因文体豁免；结构服务内容，不设章节套路。

### 各规则一句话要求

以下为速览，执行时读 references/ 原文。

**R1 先判断文体**：投给期刊会议的稿件按 paper-writing 技能的 W/M/F/A 规则；给导师、课题组或合作者的报告、记录、评审按本技能——判断结果记入风格契约卡。

**R2 结构服务内容**：记录文体不写摘要、不用编号章节；小节按内容划分，同篇标题句式不重复，同一骨架连用两次即复查；篇幅按信息密度分配。

**R3 科学要求不豁免**：事实、数字、来源链接、引语逐字（转述须标明）、结论边界与不确定性、表格图像完整性执行与论文相同的标准；过程叙述按事实口吻写，不加戏剧化。

**R4 直接陈述**：判断先行、理由紧随；删除"我们讨论得到的关键点是"一类自我导览；免责与未验证说明集中交代不循环出现；不虚构经历、细节或数据"增加人味"。

**R5 修订内容守恒**：表达层重写不改变事实——原文全部链接、引文编号、数字串、引语逐字在新版逐一核对；交付 PDF 执行排版验收。

## 场景流程

| 场景 | 做法 |
|---|---|
| 动笔前 | R1 判断文体→填[风格契约卡](templates/风格契约卡.md)写前承诺（文体去向、结构约定、禁用模式、内容红线） |
| 撰写中 | R2—R4：结构按内容划分，直接陈述，过程叙述按事实口吻 |
| 研究现状/选题论证/进展报告 | 内容核查先走 research-topic 技能的四步法，把场景、证据和已完成工作讲清，再按本技能组织表达；四步法不规定报告章节形状 |
| 重写或大幅修订 | R5 守恒核对（链接/引文编号/数字/引语逐字）＋与写前承诺对照，结果记入风格契约卡末栏 |

## 贯穿红线

- 文体判断先于动笔：论文八股写报告、报告口吻写论文都是规则集错用。
- 非论文不豁免科学要求：不虚构经历、细节或数据；负结果与未验证项如实标注。
- 修订守恒：重写不得丢链接、改数字、动引语；"表达更顺"不能改变事实集合。

## 交付闸门

1. **机械自检**：运行同仓库 paper-writing 技能 `scripts/writing_lint.py`——`parity <原稿.md> <新稿.md>` 查内容守恒（对应R5），`rhythm <稿件.md>` 查节奏与元话语（对应R4，启用与否按风格契约卡），`layout <成品.pdf>` 查中文 PDF 排版。判定两级：警告＝人工复查，失败＝不得交付；通过只代表机械项通过。成稿如需去AI味分级清理，按名使用同技能 `scripts/ai_tone_detect.py`（阈值与判据归 paper-writing 技能，流程见其成稿去AI味检测与语义判据；同样不得虚构"人味"素材）。
2. **写后对照**：按[风格契约卡](templates/风格契约卡.md)逐项核对写前承诺，偏差与处理记入末栏。

## 边界

- 适用于非投稿文体；期刊会议稿件按 paper-writing 技能，选题调研与内容核查按 research-topic 技能，研究流程管理按 research-execution 技能——均按名使用不复制规则。
- 本技能无自有脚本：写作机械自检的唯一权威是 paper-writing 技能的 writing_lint.py，按名调用，不复制副本（见顶层 AGENTS.md 例外登记）；成稿去AI味检测同用其 ai_tone_detect.py，不另建副本。
- 风格契约卡保持空白；量化参考带阈值随 paper-writing 技能 W9 维护，本卡只记录是否启用与例外。
- 规则在本目录单一维护，修订时不新增对外部文件的依赖。
