# report-writing：非论文报告写作技能

面向领域科研人员，覆盖交流报告、进展记录、评审意见等非投稿文体的写作与修订（R1—R5）。

## 适用范围

- 非投稿文体：给导师、课题组或合作者的报告、记录、评审意见
- 不适用：期刊会议稿件（paper-writing）、选题调研（research-topic）、研究流程管理（research-execution）

## 目录结构

```
report-writing/
├── SKILL.md                        # 技能入口：规则地图、场景流程、贯穿红线、交付闸门
├── references/
│   └── 非论文报告写作规范.md        # R1—R5：文体判断、结构服务内容、科学要求不豁免、直接陈述、内容守恒
└── templates/
    └── 风格契约卡.md               # 写前承诺与写后对照（空白）
```

## 使用方式

**AI 助手**：从 `SKILL.md` 进入；动笔前加载 `templates/风格契约卡.md`。

**人工使用**：直接阅读 `references/非论文报告写作规范.md`；写前填风格契约卡，写后按卡与 writing_lint 双对照（writing_lint.py 随同仓库 paper-writing 技能分发）。

## 核心立场

- 文体判断先于动笔；结构服务内容，不设章节套路
- 非论文不豁免科学要求；直接陈述，不用分析腔元话语
- 修订执行内容守恒：链接、引文编号、数字、引语逐字不丢失
- 规则在本目录单一维护；机械自检工具按名使用 paper-writing 技能的单副本
